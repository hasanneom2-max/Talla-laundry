# Talla Laundry

واجهة JavaScript بسيطة لاختيار قطع الغسيل وإرسال طلب الاستلام والتوصيل عبر WhatsApp.

## الاستخدام

أضف `app.js` إلى صفحة HTML تحتوي على العناصر التالية:

- `itemsGrid`
- `basketList`
- `custName`
- `custAddress`
- `custTime`
- `custNotes`

ثم اربط زر الإرسال بالدالة `sendToWhatsApp()`.

> تأكد من مراجعة رقم WhatsApp الموجود في `app.js` قبل النشر.
